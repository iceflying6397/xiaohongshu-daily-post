## 准确性处理

1. API 类使用“API 接入”作为大标题，因为 LiteLLM 是可自建的 SDK/网关，不是同形态的托管供应商。
2. “Agent 开发框架”改为“Agent 开发与运行”，最后两项 Hermes Agent 与 OpenClaw 明确是助手成品；其余为开发框架或库。
3. Replit 保留在原截图对应组，组名改为“工作流与应用搭建”，并注明 Replit 偏应用开发；分类是主要用途，有交叉。
4. VS Code 按当前官方文档描述为编辑器与 Agent 开发界面；不声称必须仅通过某一插件提供 AI。
5. Flowise 官方公告列明 2026-07-29 冻结开发、2026-08-10 仓库归档、2026-08-31 EOL。因此发布文案和 06 清单显式标明“已停止官方维护”，仍保留名称以对应用户截图。
6. Ollama / LM Studio 选择本地模型时可在自有机器运行；不把整个产品或全部模式写成保证不出云，实际产品也可提供云能力。
7. 未写价格、具体模型支持列表、速度排名、性能数字、免费或完全保密等保证。
8. 主要用途依据用户截图，易混淆和有状态变化的内容另查官方来源。火山方舟、Trae、扣子官网动态内容未完整返回可读正文，相关概述只保留截图所给的宽泛用途。
